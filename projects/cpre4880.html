CprE 4880 — FPGA Systems & Embedded Design

Spring 2026 · Iowa State University

CprE 4880 was a hands-on FPGA systems course focused on designing embedded systems across both hardware and software. Throughout the course, I worked directly with an FPGA development platform on projects involving video, game emulation, image processing, control systems, and real-time audio processing.

The course provided experience with FPGA hardware/software co-design, processor systems, custom logic, DMA, memory interfaces, and real-time data processing.

Course Overview

The course focused on building complete embedded systems using programmable logic and an embedded processor. Projects combined hardware design with software running on the processor system, requiring both system-level integration and debugging.

  • Designed and tested systems using an FPGA development board
  • Worked with Vivado and Vitis for hardware and software development
  • Integrated processor-system peripherals and programmable logic
  • Worked with AXI interfaces, DMA, DDR memory, and video pipelines
  • Implemented real-time signal and image processing systems

MP-0 — VGA & NES Emulation

MP-0 introduced FPGA-based video systems and processor/programmable logic integration through an NES emulation project. The system used the Zynq processing system to configure peripherals and generated video data in the FPGA before moving video frames through DDR memory using AXI VDMA for HDMI/VGA output.

  • Configured the Zynq Processing System and peripheral interfaces
  • Used AXI GPIO for buttons, switches, and LEDs
  • Configured VDMA and framebuffer memory for video output
  • Displayed NES video at 640×480 with scaling and centering
  • Implemented an interactive menu for selecting NES games
  • Created custom VHDL IP for NES/SNES-style controller input

MP-2 — FPGA Image Processing

MP-2 focused on building an FPGA-based camera and image processing pipeline. The system captured camera data, transferred video frames through DDR memory using AXI VDMA, and output the processed video through HDMI.

  • Worked with camera sensor data and Bayer-pattern imaging
  • Converted Bayer-pattern data into color video
  • Implemented software-based color conversion
  • Built an FPGA image-processing pipeline
  • Worked with AXI-Stream video and DDR frame storage
  • Measured approximately 30 FPS from the hardware image-processing pipeline

Final Project — Real-Time FPGA Audio FFT

For the final project, my team built an FPGA-based real-time audio processing system capable of capturing live audio, performing FFT analysis, outputting processed audio, and displaying frequency-domain information through a GUI.

  • Integrated an ADAU1761 audio codec using I²S
  • Configured the audio codec through register-level I²C communication
  • Used DMA to transfer audio data between the processing system and DDR memory
  • Implemented FFT analysis using KISS FFT
  • Applied DC-offset removal and Hann windowing before FFT processing
  • Implemented a triple-buffer Zip/Zap/Zop DMA pipeline
  • Built a real-time spectrum analyzer GUI

Overall Takeaway

CprE 4880 gave me hands-on experience designing embedded systems that combine hardware and software rather than treating them as separate components. Working through video, game emulation, image processing, control, and real-time audio projects gave me experience integrating FPGA logic, processor software, memory, peripherals, and real-time data pipelines into complete systems.

The course strengthened my interest in embedded systems and hardware/software integration and gave me experience that directly complements my work in firmware, robotics, and autonomous systems.
