Senior Design Project: OSCAR

January 2026 - December 2026

OSCAR (Open Source Copter for Academic Research) is a fully open-source quadcopter platform designed to support university-level research in embedded systems, controls, and autonomous flight. The system integrates custom hardware, real-time firmware, and closed-loop control algorithms to create a flexible, research-ready flight platform.

Project Website: sddec26-05.sd.ece.iastate.edu

Semester 1 Demo: Live IMU Visualization

Custom flight controller board streaming live IMU data to a custom desktop visualizer — orientation updates in real time as the board is rotated.

My Role: Firmware & Controls Engineer

I worked on the embedded firmware and flight controls stack for OSCAR, focusing on real-time sensor processing, orientation estimation, and hardware integration on STM32 microcontrollers. My work centered around IMU configuration, quaternion-based sensor fusion, ExpressLRS receiver integration, and bridging low-level sensor data into the flight control system.

  • Configured and validated IMU, barometer, and magnetometer sensors over SPI and I2C on STM32 hardware
  • Implemented quaternion-based orientation tracking using Madgwick sensor fusion algorithms
  • Developed real-time sensor acquisition pipelines for accelerometer, gyroscope, and magnetometer data
  • Integrated ExpressLRS receiver communication for low-latency pilot command input
  • Debugged register-level hardware communication issues using oscilloscopes and logic analyzers
  • Collaborated closely with hardware and software teams to validate end-to-end control functionality

Technical Contribution

  • Implemented SPI communication and initialization sequences for the ICM-40609 IMU

  • Developed embedded firmware in STM32CubeIDE using STM32 HAL/LL drivers

Controls & Sensor Fusion

A major focus of my work involved transforming raw IMU sensor data into stable orientation estimates for flight control applications. This included implementing quaternion-based orientation tracking and integrating Madgwick sensor fusion algorithms using accelerometer, gyroscope, and magnetometer data streams.

  • Implemented quaternion orientation estimation
  • Integrated Madgwick AHRS sensor fusion algorithms
  • Worked with real-time angular velocity and acceleration data
  • Helped support high-frequency flight stabilization loops
