Senior Design Project: OSCAR

January 2026 - December 2026

OSCAR (Open Source Copter for Academic Research) is a fully open-source quadcopter platform designed to support university-level research in embedded systems, controls, and autonomous flight. The system integrates custom hardware, real-time firmware, and closed-loop control algorithms to create a flexible, research-ready flight platform.

Project Website: sddec26-05.sd.ece.iastate.edu

My Role: Firmware & Controls Engineer

I served on the firmware team with a focus on flight control algorithms and acted as the primary liaison between the hardware and firmware teams. My responsibilities included:

  • Developing and tuning closed-loop attitude control algorithms (PID-based)
  • Implementing real-time sensor acquisition and filtering
  • Integrating IMU and environmental sensors with STM32 firmware
  • Debugging hardware–firmware interface issues
  • Ensuring reliable register-level communication between peripherals
  • Supporting system validation and flight testing

Technical Contribution

  • Implemented IMU data processing pipeline using BMI323 sensor
  • Designed control loops validated in MATLAB & Simulink before firmware deployment
  • Developed firmware modules in STM32CubeIDE using HAL/LL drivers
  • Analyzed datasheets to configure SPI/I2C sensor communication
  • Contributed to system-level architecture decisions for modularity and scalability

Skills & Knowledge Gained

  • Embedded C development on STM32 microcontrollers
  • Real-time systems design
  • Closed-loop control systems (PID tuning & stability analysis)
  • Sensor fusion fundamentals
  • Hardware–software integration
  • Professional engineering documentation & version control
  • Cross-disciplinary technical communication

Tools & Technologies

  • STM32CubeIDE
  • MATLAB
  • Simulink
  • BMI323 IMU
  • ENS220 Temperature Sensor
  • Git / Version Control
  • Oscilloscope & Logic Analyzer for debugging

Project Impact

OSCAR provides a customizable, research-focused quadcopter platform that enables experimentation with new control strategies, embedded architectures, and autonomous systems research. By contributing to both firmware development and system integration, I helped bridge the gap between hardware design and control implementation to ensure reliable flight performance.
